Анестезиологическое планирование по видам операций

Подсказка для предоперационного осмотра. Это тактика «по умолчанию» для пациента ASA I–II; сопутствующая патология, антикоагулянты, трудные дыхательные пути и предпочтения пациента меняют план.

Сокращения и общие правила
КЭТН — комбинированный эндотрахеальный наркоз (ингаляционный)
ТВВА — тотальная внутривенная анестезия
СД — самостоятельное дыхание (маска, канюля, HFNO)
ЛМ — ларингеальная маска 2-го поколения
ЭТТ — интубация трахеи; RSI — быстрая последовательная индукция
ДПТ / ББ — двухпросветная трубка / бронхоблокатор, ОЛВ
СА / ЭА / КСЭА — спинальная / эпидуральная / комбинированная спинально-эпидуральная
TAP, RSB, QL, ESP — поперечный, влагалища прямой мышцы, квадратной мышцы поясницы, мышцы, выпрямляющей позвоночник
PVB — паравертебральная; SAP — передняя зубчатая; PECS I/II
PENG, FICB — капсулы ТБС; фасции подвздошной мышцы (супраингвинальная)
ACB, iPACK — канал приводящих мышц; межпространство подколенной артерии и капсулы КС
ISB, SCB, ICB, AxB — межлестничная, надключичная, подключичная, подмышечная
SPG — блокада крылонёбного ганглия
ПВК / ЦВК — периферический / центральный венозный катетер
Арт. катетер: «Да» — ставится всем; «По пок.» — по показаниям
  • Артериальная линия ставится независимо от операции при ASA III–IV, тяжёлом аортальном стенозе, ФВ ЛЖ < 35 %, лёгочной гипертензии, ожидаемых вазопрессорах, частом контроле газов/Hb/глюкозы, морбидном ожирении без подходящей манжеты.
  • Нейроаксиальные методы и глубокие блоки (PVB, QL, глубокое плечевое сплетение) — только с соблюдением интервалов отмены антикоагулянтов/антиагрегантов (ASRA / протокол клиники); перед удалением эпидурального катетера после обширных резекций — контроль коагулограммы и тромбоцитов.
  • Длительные операции (> 3–4 ч) — КЭТН; ТВВА — нейрохирургия и нейромониторинг, короткие и средние вмешательства, высокий риск ПОТР (женщины, некурящие, ЛОР, маммология, пластика). Профилактика ПОТР 2–3 препаратами.
  • Полный желудок, непроходимость, кровотечение из ЖКТ, асцит, тяжёлый ГЭРБ, ахалазия — ЭТТ с RSI вместо ЛМ.
  • Суммарная доза местных анестетиков (блоки + тумесцентная + инфильтрация хирургом) считается вместе; липидная эмульсия 20 % в операционной.
